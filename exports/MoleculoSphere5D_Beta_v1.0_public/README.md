# MoleculoSphere 5D · Beta v1.0 · Public package

Classical continuum electrostatics only. Educational / hypothesis-generation tool.  
No biological claim without independent validation.

## Layout

| Folder | Content |
|--------|---------|
| `params/` | Locked physics JSON + kernel validation |
| `validation/` | Public validation CSVs and reports |
| `figures/` | Fig1–Fig4 (public Fig. 2 = KSRRRAR + Pb²⁺ only) |
| `paper_tables/` | Publication tables (CSV/JSON) |
| `docs/` | Manual, examples, preprint skeleton, keep/drop policy |
